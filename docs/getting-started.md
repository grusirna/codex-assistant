# 开始使用

1. 从[产品网站](https://codexon.cc/)或本仓库正式 Releases 下载与你的平台相符的安装包。
2. 安装并打开「codex · 管家」。Windows 使用 `.exe` 安装器；Apple Silicon Mac 使用 `.dmg`。
3. 在管家中安装或启动官方 Codex，选择官方账号或配置自己的模型接入。

Windows 安装包采用未签名策略，系统可能显示 SmartScreen 提示。Mac 安装包采用临时签名，系统可能提示无法验证开发者。请核对下载来源、文件名和发布页 SHA-256；不要把未通过验收的构建候选当作正式版本安装。

反馈时请提供系统版本、管家版本和复现步骤。请先移除 API 密钥、访问令牌、账号信息和私人会话内容。
