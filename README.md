# codex · 管家

为 Windows 和 Apple Silicon Mac 提供 Codex 的安装、中文初始化、更新与启动管理，也支持配置第三方模型接入。

管家使用官方 Codex 客户端。官方账号、API 密钥和会话仍由官方 Codex 管理。

- [产品网站与现有下载](https://codexon.cc/)
- [使用说明](docs/getting-started.md)
- [GitHub 下载](https://github.com/grusirna/codex-assistant/releases)
- [反馈问题](https://github.com/grusirna/codex-assistant/issues)

GitHub Releases 将提供经过验收的正式安装包；当前请通过产品网站获取已发布版本。Windows 支持 64 位系统，Mac 支持 Apple Silicon（M 系列芯片）。

本仓库提供产品介绍、文档、反馈和发布入口。管家源码保持私有；本仓库的源码压缩包包含这里的公开文件。软件使用权不等同于源码开源授权。
